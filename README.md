# موجة — مشغّل فيديوهات القنوات

هذه نسخة ثابتة مناسبة للنشر على HTTPS عبر GitHub Pages. المشغّل يستخدم YouTube IFrame Player الرسمي لكي يبقى الفيديو داخل صفحة موجة، ولا ينزّل الفيديو أو يعيد استضافته.

## النشر على GitHub Pages

1. افتح **Settings → Pages** في المستودع.
2. في **Build and deployment** اختر **GitHub Actions**.
3. شغّل workflow باسم **Deploy Mawja to GitHub Pages** من تبويب **Actions** إذا لم يبدأ تلقائيًا.
4. افتح رابط الموقع المنشور من متصفح Chrome أو أضِفه للشاشة الرئيسية.

**مهم بخصوص خصوصية المستودع:** المستودع المرتبط حاليًا خاص. على خطة GitHub Free، يتطلب النشر العام عبر GitHub Pages مستودعًا عامًا. لن يتم تغيير خصوصية المستودع تلقائيًا؛ انشره للعامة فقط إذا كنت موافقًا على أن ملفات الموقع ستكون مرئية للجميع، أو استخدم خطة تدعم Pages للمستودعات الخاصة.

## تحميل فيديوهات القنوات

قائمة الفيديوهات تستخدم YouTube Data API v3، لذلك يلزم إدخال مفتاح API من إعدادات موجة. فعّل API في Google Cloud، ثم قيّد المفتاح باستخدام **HTTP referrers** لنطاق الموقع بعد نشره، وقيّده أيضًا بواجهة **YouTube Data API v3**. لا تضع المفتاح داخل ملفات المستودع.

## حدود التشغيل

- الفيديوهات التي تسمح بالتضمين تعمل داخل موجة.
- إذا منع صاحب الفيديو التضمين (خطأ 101 أو 150)، فلا يمكن للموقع تجاوز هذا المنع؛ سيظهر رابط فتح الفيديو على YouTube.
- التشغيل يحتاج الإنترنت. قد يمنع المتصفح التشغيل التلقائي بالصوت، وفي هذه الحالة اضغط تشغيل داخل المشغّل.
- استضافة HTTPS تساعد في حل خطأ 153 الناتج عن غياب عنوان الصفحة المرجعي عند فتح الملف محليًا أو من عارض ملفات.
